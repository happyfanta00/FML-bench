I made three changes to iCaRL to improve average incremental accuracy. I have not run this yet, so the gain over the 0.5925 baseline is unconfirmed.

1. **Feature distillation.** Each incremental stage adds a cosine-similarity loss between the new and old network's penultimate features, based on the LUCIR less-forget constraint. Its weight is `sqrt(known/new)`, so it constrains more as the share of old classes grows. This keeps the shared embedding stable, which should help nearest-mean-of-exemplars (NME) classification, since NME relies on those features.
2. **Weight Aligning (WA).** After each incremental stage, the new-class classifier weights are rescaled so their average norm matches the old-class weights. This targets the bias toward recent classes in the CNN classifier. It does not change the features, so exemplar selection and NME are unaffected.
3. **Cheaper old-network pass.** The frozen old network now runs under `torch.no_grad()`. This only saves time and memory; the loss values are the same.

The base task, the logit distillation, and the learning-rate schedules are unchanged.

    def _weight_align(self, increment):
        net = (
            self._network.module
            if isinstance(self._network, nn.DataParallel)
            else self._network
        )
        try:
            with torch.no_grad():
                weights = net.fc.weight.data
                newnorm = torch.norm(weights[-increment:, :], p=2, dim=1)
                oldnorm = torch.norm(weights[:-increment, :], p=2, dim=1)
                gamma = torch.mean(oldnorm) / (torch.mean(newnorm) + EPSILON)
                net.fc.weight.data[-increment:, :] *= gamma
            logging.info("Weight aligning, gamma = {:.4f}".format(gamma.item()))
        except Exception as e:
            logging.info("Weight aligning skipped: {}".format(e))
